OATH OF POWER — INSTALLABLE APP PACKAGE

Upload these five app files to the ROOT of your existing GitHub Pages repository:
- index.html (new game homepage)
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

IMPORTANT: first rename your old index.html to index_old.html and commit that change. Then upload these files and commit. Keep every file at the repository root (do not place them in a subfolder).

Install from the published HTTPS GitHub Pages website:
- iPhone/iPad: open the site in Safari > Share > Add to Home Screen.
- Android/Chrome: open the site and choose Install App / Add to Home Screen.
- Mac Safari: File > Add to Dock. On supported Chromium browsers, use the install icon or browser menu.

After publishing, open the site online once so the app can cache its files. The game can then open offline after that initial load. Saved progress stays in that browser/device only.
